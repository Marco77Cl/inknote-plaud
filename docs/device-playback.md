# InkNote 设备回放

准备记录 / 已保存页面向下拨进入录音回放。每屏显示 5 条录音，刚保存后进入会选中首项本次文件。新版通过 .inknote-order 记录保存顺序；旧文件按修改时间、目录枚举次序回退，无法恢复完全缺失的历史精确顺序。

- 未播放：上下拨移动选中箭头，同页只局部刷新箭头；单击拨轮进入播放页。
- 播放中：单击拨轮暂停；暂停后再次单击继续。
- 播放 / 暂停时：上下拨调节音量。
- 双击 BOOT 或双击拨轮：停止播放并返回列表；列表页双击返回录音页。
- 返回录音页后，单击拨轮开始新录音；向上拨仍为传输模式。

页面显示文件名、序号、录音总时长和音量。总时长不是实时播放进度。没有删除操作；读取 /sdcard/recordings/ 中已完成的 InkNote PCM WAV，忽略未完成 .part。

使用原厂音频播放器和扬声器通道，录音和回放互斥，返回后恢复录音配置。待本次构建、刷写和用户实机听音确认后验收。

旧固件备份：backups/playback-before/inknote_system.bin；应用分区地址 0x10000。

构建验证：ESP-IDF 编译通过，应用大小 0xdad4e0，应用分区剩余约 9%。tests/check_playback_validation.py 已通过，覆盖有效 WAV、截断、声道/采样率不符、奇数字节、空音频及非法文件名。实际播放、暂停返回与再次录音待设备听音验收。

用户已确认前版播放、暂停、返回后再录音正常。本次列表版编译和排序测试通过，列表实机显示与光标残影待确认。
