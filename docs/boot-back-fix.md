# InkNote 返回按键与操作提示（2026-10-21）

按用户选择保留双击 BOOT 返回；双击拨轮也可返回。单击拨轮用于开始、停止录音。

- 准备 / 已保存：向上拨进入传输，双击 BOOT 返回上级。
- 正在录音：双击 BOOT 请求停止，WAV 完成写入并关闭后返回。
- 正在保存：记住返回请求，等待写入完成；保存失败留在错误页，避免隐藏失败。
- 传输页：双击 BOOT / 双击拨轮返回，停止正在进行的下载，TF 原文件保留。

原有通用按键读取一次清除全部事件，仅返回最低位；墨水屏同步刷新期间，拨轮按下/松开与双击同时积累时会丢失双击。InkNote 现在只读取相关动作位并优先处理返回，不改动原厂其他页面。

传输退出增加线程安全停止标记，在哈希和发送分块之间检查。正在阻塞的网络发送仍受原有 5 秒超时限制；墨水屏刷新仍有物理延迟，不声称即时返回。

验证：ESP-IDF 编译通过；主机输入事件测试覆盖双击与按下/松开积累、返回与其他动作同时到达、单击 BOOT 不触发返回；已检查录音页、传输页提示图。设备刷入与实际按键验收另见本次日志/会话。

回退备份：backups/boot-fix-before/inknote_system.bin。仅写应用分区 0x10000。
