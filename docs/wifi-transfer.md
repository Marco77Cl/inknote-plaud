# InkNote Wi-Fi 传输（开发中）

更新：2026-10-17。

## 使用路径

1. 从原厂主菜单进入 InkNote，等待「准备记录」或「已保存」。向上拨进入传输页。
2. Mac 连接页面上的 `InkNote-XXXX` 热点，输入本次临时 Wi-Fi 密码。
3. 打开 `apps/inknote-studio/build/InkNote Studio.app`，点击「热点直连地址」，输入设备六位配对码并连接。
4. 选择录音下载，或下载全部新录音。默认保存在 `~/Downloads/InkNote/<设备地址>/`。
5. 下载完成后双击设备拨轮或使用原系统 BOOT 返回操作退出；热点关闭，Mac 可重新连接家中网络。

热点传输不提供互联网转发；Mac 使用该 Wi-Fi 时可能暂时不能上网。配对码与热点密码每次进入页面重新生成。卡内原件保留，不提供删除 API。

## 实现与数据完整性

- 设备沿用已有 Wi-Fi 驱动，进入传输页时从 STA 切到 APSTA，创建临时 WPA2 热点；退出恢复之前模式并销毁本次创建的 AP 接口。
- 传输页不录音。仅列出规范命名且 WAV 头与文件长度一致的已保存 16 kHz / PCM16 / mono 录音，排除未完成 `.part`。
- HTTP 8081；配对获取本次内存 token。列表、下载需 Bearer token。密码猜错五次限流一分钟。
- Mac 将下载写入 `.part`，支持 Range 续传；校验长度和 SHA-256 后才改名为正式 WAV。损坏文件隔离为 `.bad-*`。现有未验证文件保留为 `.previous-*`。
- HTTP 本身不提供 TLS，设备热点使用 WPA2；不向云端上传。热点每次仅允许一个客户端。
- 本版本要求系统 Wi-Fi 驱动已处于 STA 模式，其他模式显示错误并允许返回；不重建或覆盖原厂配网信息。

## 已有验证与待验收

- 局域网版本和热点版本固件编译通过；Mac 应用构建通过。
- 原局域网版本已实机进入传输页，用户读出六位配对码，证实不依赖 TF 字体的修复有效。
- Mac 下载器本地模拟测试通过：中断续传、哈希、未授权、无效 Range、损坏隔离。记录：`logs/inknote-studio-transfer-tests.log`。
- 热点页面使用实际 C 渲染器生成并目视检查，示例码仅为预览。
- 待实机验收：热点创建、Mac 获得设备网段地址、配对及真实 WAV 下载、下载 SHA-256、Mac 播放、退出热点并再次进入。
